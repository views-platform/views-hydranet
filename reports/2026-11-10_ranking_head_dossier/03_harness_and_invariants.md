# 03 — Harness and invariants: what must be in place before the first run

**Serves:** the *"could we find out safely"* precondition on Simon's question — the guardrails that
make a ranking-body experiment interpretable, discovered in this repo rather than templated.

Audited 2026-11-10. ⭐ **Headline: most of the harness already exists.** What follows separates what
is reusable from what is missing, and names the guardrails that exist but are **never reached**.

⚠️ **A word collision, flagged so it is not read as drift.** In this document "gate" mostly means
*guardrail*, not the occurrence head. The occurrence head is written **the occurrence head** here
throughout. `02_design` keeps the modelling sense and is the document the body-vs-occurrence ratio
test asserts on.

## 1 Invariants — three kinds, not one

The cardinal mistake is treating every current behaviour as sacred.

### 1a ⛔ HARD — never break. An experiment that violates one is invalid, not interesting.

1. **The stable baseline stays the default and byte-identical when the new path is off.** The
   reference is real and testable: `tests/distributions/test_parity_anchor.py:50` asserts
   `_emit_magnitude` byte-for-byte against a recorded golden for all six legacy
   `output_distribution` values.
2. **Fail loud, never silent-clamp.** `ADR-008`: `logger.error` precedes every `raise`.
   `ADR-003`: on semantic ambiguity, fail — do not guess.
3. **Non-finite output halts the run.** `training_engine.py:1810-1821` refuses to backpropagate a
   non-finite loss by name (*"this is a bug upstream in the loss, not a skippable window"*);
   `integrity_guardian.py:32-77` checks loss, parameters and gradients per lesson.
4. **Reproducibility:** `lock_entropy` before training, seeds recorded in the emission manifest.
5. **Full suite green**, collection ≥ 2,443, lint clean.
6. ⛔ **`C-351`:** every number names its population, transform, estimator, and whether it is
   normalised and by what (`GLOSSARY.md` §5e).

### 1b ⭐ DELIBERATELY CHANGED by this programme — each behind a default-off flag

Stated so reviewers do not defend behaviour we intend to replace.

| current behaviour | what replaces it | the flag |
|---|---|---|
the body emits `(μ, θ)` and is trained by NB negative log-likelihood | the body emits **one scale-free score** and is trained by a level-indexed listwise loss (`02 §3`) | a new `output_distribution` / loss-registry entry, default off |
the body's magnitude is parametric | magnitude is drawn from the empirical pool at the cell's rank (`02 §1`) | the rank-coupled emitter, default off |
the regression target enters the loss as a raw count | it enters as a **dyadic rating level** (`02 §2`) | part of the same entry; the transform is internal to the loss |

⇒ Exactly **one** mechanism moves at a time, and the first two are separable: the loss can be
trained and its ordering read with **A's existing emission**, which is `04` phase 3.

### 1c ⚠️ RESPECT WHILE CHANGING — not targeted, breakable in passing

1. **The occurrence head is untouched.** It is calibrated (median `|p − observed|` **0.0054** over
   842,634 cell-months) and this programme changes nothing about it. It appears in three licensed
   roles only (`00 §⭐⭐`).
2. **The h = 1 feedback-invariance property** and the byte-exact train↔inference feedback parity
   (`tests/train/test_feedback_parity.py`) — a new body changes what is fed back at every h ≥ 2.
3. **`forecast_composition` is read at four sites**, two of them the rollout feedback
   (`hydranet_inference.py:519, 1056, 1127, 1752`). Changing the composition to read the body also
   changes what the model feeds itself.
4. **The scale-free score is not a count.** Nothing downstream may interpret it as one — the
   `expm1`/activation path and every diagnostic that assumes count space.
5. **`ADR-078`:** horizons are selectable for emission, never for computation.

## 3 New harness this programme requires — the gaps that come first

### 3.1 ⛔ A new loss *shape* needs its own dispatch branch

The registry does not route it. Dispatch is `isinstance`-based at `training_engine.py:916-923` and
`:936-946`, with exactly three shapes known: point `[B,H,W]`, family `[B,H,W,n_params]`, quantile
`[B,H,W,K]`. **A listwise criterion needs a fourth branch**, and adding it is a change to the
dispatcher — which is the one thing `ADR-067`'s seam was built to avoid. ⇒ Either the loss conforms
to the family shape with `n_params = 1`, or the seam is widened deliberately and that is a design
change, not an implementation detail. **Phase 1 work.**

### 3.2 ⛔ No registered loss couples cells to each other

All 14 entries in `LOSS_REG_REGISTRY` (`utils/utils.py:48-139`) and every family NLL reduce a strict
per-cell term by `.mean()`. The two near-misses are not ordering couplings: `count_mean`
(`count_mean_loss.py:47-53`) divides by a batch-level scalar, and `QuantileLoss`
(`quantile_head.py:152-158`) couples the `K` channels *of one cell*. ⇒ **A listwise term would be
the first loss in this repo whose value depends on cells' relative order.** Nothing existing
exercises that path. **Phase 1 work: the numerics first, tested before anything trains.**

### 3.3 ⛔ Nothing asserts the criterion returned a scalar

A search for `ndim == 0`, `dim() == 0`, `numel() == 1` across `training_engine.py` and
`distributions/` returns no hits. A non-scalar return either fails at `torch.stack`
(`training_engine.py:1117`) or **broadcasts silently** if its rank happens to match. For a loss
whose reduction is novel, that is the exact `C-417` shape — a defect a downstream identity cancels.
**Phase 1 work.**

## 4 Experiment protocol

1. **One variable at a time**, each behind its own default-off flag. The loss and the emitter are
   separable and are separated (`04` phase 3 before phase 5).
2. **Pre-register, then run.** The plan is committed before the script exists — and the scoring rule
   is declared **ex ante** (`C-3531`). This is why `05` is a stub.
3. **Cheap readout before expensive.** The patch→global ordering probe costs CPU minutes and bears
   directly on the finish line; it runs before anything trains to convergence.
4. **A declared no-op control** that must land at zero on the primary criterion. If it does not, the
   criterion is broken — not the arm.
5. **The margin is in units of measured seed dispersion**, never percent (`C-392`: seed noise on
   `MCR_field` is **84×** `FAO-02`'s 1% margin).
6. **Falsifier honesty.** A pre-registered falsifier that fires ends the hypothesis as stated; it is
   documented, not rescued ad hoc.
7. ⛔ **Up-front work informs and gets no veto** (`00 §6`).

- [ ] fail-loud guards: non-finite, device, shape contract
- [ ] full suite green, collection ≥ 2,443, lint clean
- [ ] ⛔ **a pre-registration exists** — hypothesis, the one variable, predictions, pre-committed

- [ ] the retrain-free readout adapted to a scale-free score (`body_mean_dump_dir` writes a mean;
      a score is not a mean)
