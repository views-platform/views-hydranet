# Scope — what this dossier does NOT establish

Written before the run, so that nothing here is a retrofit.

## Exclusions

1. **One seed.** Seed 42 only. On this very board, `violet_visitor` and `bright_starship` are both
   160-lesson `nb` `soft_gate` models and land on **opposite sides** of the pre-registered verdict
   (REAL through h18 vs ARTIFACT from h6). Between-run spread is therefore large and unquantified.
   Nothing here is a multi-seed claim, and a positive result is an escalation trigger, not a
   conclusion.

2. **One vehicle for the treatment.** The arms run on `violet_visitor` only. `purple_alien`,
   `blazing_meteor` and `bright_starship` are scored in `rescore.csv` but no realism arm has ever been
   run on them.

3. **The vehicle contrast confounds two variables.** `truncated_smoke` differs from `violet_visitor` in
   *both* training length (40 vs 160 lessons) *and* body family (`truncated_nb` vs `nb`). This
   experiment cannot separate them, and no existing run can either — all four models in `rescore.csv`
   are 160-lesson and none is `truncated_nb`. Every comparison here reads "smoke vehicle vs production
   vehicle", **never** "training length".

4. **One target.** `sb` only. `ns`/`os` are scored in `rescore.csv` but not by these arms.

5. **`spatial_scramble` inherits C-291's irreducible confound** — destroying clustering necessarily
   breaks alignment with the statics, because plausible locations *are* the clustering. That arm reads
   as "spatial structure **and** its geographic grounding".

6. **The control is a re-score, not a re-run.** `identity` is the preserved 2026-08-12 production cube.
   That is *stronger* than a re-run for reproducibility (F1 confirmed it bit-for-bit) but it means the
   control was generated by the code as it stood on 2026-08-12, while the treatment arms are generated
   by today's code. F4 (h=1 identical across arms) is the guard that would catch a divergence in the
   inference path; if F4 passes, the paths agree where no feedback is involved.

7. **No fix is proposed or tested.** This measures whether a mechanism replicates. It does not attempt
   to repair anything.

8. **AP has no interval here.** The origin-block CI in `rescore.csv` is on the **CRPS differential**;
   ΔAP enters the verdict as a point estimate. This dossier does not add a CI to ΔAP, so an AP
   difference is a measurement, not a significance claim.
